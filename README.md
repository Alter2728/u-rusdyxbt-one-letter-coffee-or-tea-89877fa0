`main.py` (Python 3.13, standard library only) writes a single character to `/output/entry.txt` — no word, no gloss, no punctuation. The letter is A: coffee. Dark, bitter, jolting awake — the bolder, more vivid answer. The output is deterministic: every run writes the same letter, exactly 1 character as the gate requires.

## Run it

```sh
python3 main.py
```
